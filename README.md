# AI Resume Analyzer

AI Resume Analyzer is a full-stack web application that helps job seekers evaluate and improve their resumes using artificial intelligence. Users can upload their resume in PDF format and provide a job description, and the system analyzes the resume against the job requirements to generate an ATS (Applicant Tracking System) score, identify matching and missing skills, provide personalized improvement suggestions, and generate potential interview questions.

Built with Next.js, TypeScript, Tailwind CSS, FastAPI, and Google's Gemini AI, the application offers a modern and intuitive user experience while delivering intelligent resume insights. The project demonstrates full-stack development, AI integration, file handling, API communication, and responsive UI design.

### Key Features

* Upload and analyze PDF resumes
* ATS score calculation
* Skill matching and gap analysis
* Personalized resume improvement suggestions
* AI-generated interview questions
* Modern AI-themed responsive interface
* FastAPI backend with Gemini AI integration

### Tech Stack

**Frontend:** Next.js, TypeScript, Tailwind CSS, Framer Motion, Axios

**Backend:** FastAPI, Python, Uvicorn, PyPDF

**AI:** Google Gemini API

### Use Case

This application helps students, freshers, and professionals optimize their resumes for specific job roles, increasing their chances of passing ATS screening systems and securing interviews.
